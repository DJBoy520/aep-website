# AEP官网(aep.org.cn) Web界面改版PRD交付清单

## 一、产品定位 & 目标用户（前置核心说明）

### 1. 目标用户人群
本次官网改版服务三类核心用户，所有页面设计优先适配分层阅读：
1. **普通业务用户/项目对接方**：政企项目人员、物联网/车联网集成方、存证业务人员，不懂密码学、不懂PKI协议，只关心「能用在哪、解决什么问题、怎么对接」。
2. **入门开发者**：需要快速上手集成AEP签名、时间戳、设备认证能力，需要案例、demo、极简接入教程。
3. **专业技术工程师/密评检测人员**：商用密码工程师、PKI研发、标准检测人员，需要完整协议规范、报文定义、国密合规依据、版本标准文档。

### 2. 现有产品 & 官网核心痛点
1. **用户门槛极高**：全站纯技术协议文风，无通俗介绍，外行进入页面3秒无法理解AEP是什么、有什么用。
2. **信息无分层**：小白教程、专业协议、底层报文、标准规范全部混排，新用户劝退、专业用户查找效率低。
3. **无产品价值输出**：只讲技术原理，不讲业务价值，无法支撑项目洽谈、客户宣讲、对外科普。
4. **无可视化体验入口**：只有文档和命令行说明，无在线演示，用户无法直观验证产品能力。
5. **导航逻辑混乱**：以「技术文档目录」为逻辑，而非「用户使用路径」，不符合普通用户浏览习惯。

### 3. 改版核心目标
1. **分层展示内容**：小白看应用、开发者看接入、专家看标准，三类用户互不干扰。
2. **官网产品化**：从「协议文档站」升级为「AEP产品官方门户」，可用于对外展示、项目对接、客户科普。
3. **降低理解成本**：0基础用户可快速读懂产品价值，开发者可快速上手，专家可快速查阅标准。
4. **具备演示能力**：提供可视化在线工具，让用户不用部署代码即可体验AEP核心能力。

---

## 二、整体改版通用规范（全站统一）

1. **文风强制分层**
   - 首页、介绍页、快速上手：通俗商业语言，零晦涩术语
   - 技术文档：提供「简易版 / 专业完整版」双模式切换
2. **全站术语释义**
   - 所有专业名词（PKI、TSA、可信时间戳、国密、抗量子、IAM、证书链）全部增加悬浮Tooltip中文释义
3. **页面排版规范**
   - 杜绝大段密集文字，短句、分段、卡片、图标化展示
   - 所有代码块支持「一键复制+语法高亮」
   - 全局增加面包屑导航，清晰展示用户当前页面位置
4. **适配要求**
   - 全页面自适应PC/移动端，表格、代码块支持横向滚动

## 三、首页 强制改版需求（P0最高优先级）

### 1. 首屏完全重构（核心：3秒讲清产品）
- **首屏主标题（中文优先）**：
  `AEP新一代数字信任协议｜轻量化可信身份与时间认证体系`
- **副标题（通俗价值，对外商用口径）**：
  `适配车联网、物联网、电子存证场景，基于国密标准设计、预留抗量子能力，简化传统PKI复杂架构，提供标准化签名、验签、可信时间戳全能力。`
- **首屏三大核心行动按钮（固定展示）**：
  1. 快速入门（面向小白/开发者 默认入口）
  2. 在线体验（可视化工具入口）
  3. 技术规范（面向密码工程师/检测人员）

### 2. 首页增加「四大业务场景卡片」
卡片简洁无技术废话，用于客户快速看懂落地场景：
1. **车联网可信认证**：车辆设备身份可信、传输数据防篡改
2. **物联网海量设备认证**：轻量化证书管理，适配海量终端设备
3. **电子证据固化存证**：权威可信时间戳，实现电子数据不可篡改固化
4. **商用密码合规适配**：完全兼容国密标准，满足密评、合规检测要求

### 3. 首页删除冗余底层原理
首页不展示ASN.1、报文结构、协议字段、密码学原理，全部迁移至专业文档区。

## 四、全站导航栏重构需求（P0）

新版导航完全用户视角，替换原有技术目录视角：
1. 产品介绍（是什么、能解决什么问题、适用场景）
2. 快速上手（零基础教程、接入示例、SDK指引）
3. 在线工具（网页演示、签名验签、时间戳体验）
4. 技术规范（协议原文、标准引用、国密合规文档）
5. 开源仓库 & 资源下载
6. 常见问题FAQ
7. 关于项目

---

## 五、文档体系改版需求（P0）

### 1. 文档双模式切换（全站文档通用）
- **默认模式：简易科普版**
  - 移除公式、报文结构、底层协议细节
  - 以「步骤、流程、作用、使用方法」为主，适配业务用户和新手开发者
- **切换模式：专业完整版**
  - 保留全部协议原文、报文定义、标准依据、参数细节、密码学逻辑，适配工程师、密评检测场景

### 2. 新增侧边固定术语词典
- 文档页右侧悬浮可折叠词典，汇总所有核心名词解释，解决小白看不懂专业词的问题。

---

## 六、在线演示工具页面改版（P0核心体验）

解决痛点：只有文字命令行，用户无法直观感受产品能力
1. 网页内嵌可视化AEP工具，无需本地部署
2. 支持：文本/内容 一键签名、加盖可信时间戳、在线验签
3. 增加「一键填充示例数据」按钮，降低用户测试门槛
4. 结果区分双展示：
   - 普通用户：可视化简洁结果（验证成功/失败、时间信息、可信状态）
   - 技术用户：原始JSON/报文详情（可切换查看）

---

## 七、次级优化需求（P1 体验升级）

1. **全站版本化管理**：页面标注AEP协议版本号，文档迭代可追溯
2. **智能搜索优化**：支持中文自然语言搜索，搜索「时间戳使用」「设备接入」优先展示简易教程
3. **FAQ页面建设**：高频问题标准化解答
   - AEP和传统PKI的区别
   - 是否兼容国密标准
   - 适用落地场景
   - 接入开发门槛
4. **页面视觉优化**：分割线、留白、图标优化，告别密集文字观感

---

## 八、交付验收标准

1. 外行用户打开首页，10秒内可以看懂AEP是什么、用在哪、有什么价值
2. 新手开发者可通过「快速上手」独立完成基础能力了解与接入
3. 专业工程师可快速找到完整协议、合规标准、报文规范
4. 官网具备可对外展示、可项目宣讲、可客户科普的产品门户能力
5. 所有术语有解释、所有文档分层、所有功能有可视化演示入口
